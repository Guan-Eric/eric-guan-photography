# StudioFront Content & Blog Plan

> Step 6 of `docs/SAAS-SUCCESS-PLAYBOOK.md`, expanded into a publishable editorial plan.
>
> **Goal:** Rank for high-intent “switching / alternative / software” searches, earn LLM citations, and convert photographers into trial / LTD / paid plans.
> **Audience:** Real estate photographers and small multi-shooter studios evaluating Aryeo, Spiro, HDPhotoHub, or Drive/Dropbox delivery.
> **Rule:** Every piece has one primary keyword cluster, one job (educate or compare), and one CTA.

---

## 1. Strategy in one page

### What we write for

| Intent | % of early calendar | Example |
|---|---|---|
| **Commercial** (ready to switch) | ~50% | Aryeo alternative, vs pages, pricing software |
| **Problem** (feels the pain) | ~30% | No agent login, slow unlock, monthly rent in slow months |
| **Category** (learning the market) | ~15% | Best RE photo software roundups |
| **Brand / trust** | ~5% | Case studies, migration stories |

### Positioning to repeat (without sounding salesy)

1. White-label on **their** brand  
2. Agents get a **link**, not an account  
3. **Pay-in-gallery** unlock  
4. **Per-listing / usage-first** economics vs high fixed rent  
5. Photographer-owned data (not a portal lock-in story)

### What we do **not** write early

- Generic “how to take better listing photos” (huge competition, weak SaaS conversion)
- AI-hype listicles with no product tie-in
- City SEO that only promotes Eric Guan Photography (dogfood site owns that; platform blog stays category-level)
- Fake “#1 tool” posts without criteria

### Formats

| Format | URL pattern (suggested) | When to use |
|---|---|---|
| Alternative | `/blog/aryeo-alternative` | Highest priority commercial |
| Versus | `/blog/aryeo-vs-studiofront` | Decision stage |
| Roundup | `/blog/best-real-estate-photography-software` | Category capture |
| How-to / playbook | `/blog/deliver-listing-photos-without-agent-login` | Problem → product |
| Economics | `/blog/per-listing-pricing-vs-monthly-software` | Pricing objection |
| Migration | `/blog/switch-from-aryeo` | Late funnel |
| Case study | `/blog/case-study-{studio}` | Trust after you have users |

Until a `/blog` route exists, publish as static marketing pages under `/saas/...` or Notion→site; **do not wait on perfect CMS** to start drafts.

## 2. Buyer personas (write to these)

### Persona A — Solo RE photographer (primary)

- Pays Aryeo or juggles Drive + invoices  
- Hates paying full rent in slow months  
- Wants agents to stop asking for logins  
- Decides in days, not months  

**Content they finish:** alternatives, pricing math, “without agent login,” migration checklists.

### Persona B — 2–5 person studio owner

- Needs seats, branding, consistent delivery  
- Cares about white-label + Connect payouts  
- Compares Aryeo / Spiro / HDPhotoHub feature matrices  

**Content they finish:** vs pages, team workflows, onboarding time-to-live.

### Persona C — Agent / brokerage ops (secondary, not buyer)

- Rarely buys StudioFront  
- Shares posts that reduce friction (“send the gallery link”)  
- Useful for backlinks and social proof, not primary SEO target

## 4. Publishing phases

### Phase 0 — Prep (before public posts)

- [ ] Confirm public product name + domain on all drafts  
- [ ] Screenshot kit: booking, proof gallery, pay unlock, admin board, pricing  
- [ ] Pricing facts locked ($49 / $99 / $149 + PAYG $5/listing) — cite only what is live  
- [ ] Analytics + Search Console on apex  
- [ ] CTA variants: Start 14-day trial · See plans · Join LTD (when live)  
- [ ] Author bio (Eric / StudioFront) for E-E-A-T  

### Phase 1 — Week 1–2 (ship the 5 money pages)

These five are non-negotiable. Publish even if short (1,200–1,800 words) and expand later.

### Phase 2 — Weeks 3–8 (1–2 posts/week)

Fill competitor, migration, and economics cluster.

### Phase 3 — Months 3–6 (steady state)

Case studies, quarterly roundup refreshes, objection posts from support/sales calls.

### Phase 4 — Ongoing maintenance

- Refresh “best of {year}” and pricing numbers quarterly  
- Add new competitor pages only when search demand or sales objections justify them  
- Turn Reddit/support questions into posts within 7 days when the same question appears twice

## 8. Page brief template (copy for every draft)

Use this at the top of each draft doc:

```md
# {Title}
Slug: /
Primary keyword:
Persona: A / B
Funnel stage: TOFU / MOFU / BOFU
CTA:
Competitor mentions:
Must-include screenshots:
Internal links:
External links (optional, reputable only):
Disclosure: We build StudioFront.
Publish target date:
```

### Writing rules

1. Lead with the photographer’s job, not the product name.  
2. Put the comparison table above the fold on vs/alternative posts.  
3. Include real numbers (plan prices, example monthly math). Update when pricing changes.  
4. Add an FAQ (4–6 questions) for featured-snippet / LLM extraction.  
5. End with a single CTA button target — no three competing asks.  
6. Disclose affiliation clearly on roundups.  
7. Keep claims courtroom-safe: no invented Aryeo outages or unverified pricing.

### Length targets

| Type | Words |
|---|---|
| Alternative / vs | 1,500–2,500 |
| Roundup | 2,000–3,000 |
| How-to / economics | 1,200–1,800 |
| Case study | 900–1,400 |

## 9. Distribution (each post leaves the building)

Same day as publish:

1. **Email** waitlist / LTD list (short excerpt + link)  
2. **LinkedIn** — 5–8 line founder takeaway, not a link dump  
3. **X** — one sharp contrast (e.g. “Agents don’t need another password”)  
4. **Facebook groups** — only where self-promo is allowed; lead with the how-to  
5. **Reddit** — answer a real thread; link only if it directly helps  
6. **Sales** — add best URLs to DM snippets for Aryeo users  

Optional later: guest posts on photographer blogs, local association newsletters, partner roundups.

## 10. Measurement

### Leading indicators (week 1–8)

| Metric | Target direction |
|---|---|
| Pages indexed | All Phase 1 URLs |
| GSC impressions for “Aryeo alternative” / “vs” queries | Up and to the right |
| Avg. engagement time | > 2 minutes on money pages |
| CTA clicks from blog → `/signup` or `/pricing` | Tracked per post |

### Lagging indicators (month 2+)

| Metric | Why it matters |
|---|---|
| Organic trial starts | Content → revenue |
| Assisted conversions | Blog in path before signup |
| Ranking for P1–P5 keywords | Moat |
| Brand search (“StudioFront”) | Awareness |

### Kill / double-down rules

- **Double-down** if a post gets impressions + CTR but weak conversion → fix CTA/screenshots  
- **Expand** if it ranks page 2 → add FAQ, table, screenshots, internal links  
- **Pause lookalike topics** if zero impressions after 8–10 weeks indexed → re-keyword or merge
